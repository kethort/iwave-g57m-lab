# Security

## Reporting a vulnerability

Please do not open a public issue for a suspected security vulnerability.
Use GitHub's private vulnerability reporting feature for this repository.

Include the affected release, host distribution, Vitis version, and enough
reproduction detail to evaluate the report without including credentials,
private keys, proprietary boot artifacts, or device secrets.

## Release scope

This repository distributes a precompiled application and container packaging.
It does not include the C++ or QML source. Configuration examples contain no
credentials and should be customized with local paths and network settings.
